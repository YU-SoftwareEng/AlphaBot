# Software Requirements Specification (SRS) (& System testing)

**Project title:** AlphaBot

**Project description:** AlphaBot은 인공지능 기반 주식 챗봇 웹 애플리케이션으로, 사용자가 자연어로 질문을 입력하면 주식 종목의 실시간 정보, 재무 데이터, 뉴스 및 공시 요약을 대화형 인터페이스를 통해 제공한다. 본 시스템은 단순한 종목 검색을 넘어, 사용자 계정 관리, 검색 기록 및 카테고리 관리, 커뮤니티 댓글 기능까지 포함하여 투자자가 보다 효율적이고 편리하게 주식 관련 정보를 탐색할 수 있도록 설계되었다. 또한 사용자 맞춤형 대시보드, 재무 차트 시각화, 보안 및 데이터 보호 기능을 통해 안정성과 신뢰성을 강화하며, 사용자는 북마크, 휴지통 등 다양한 보조 기능을 활용해 자신만의 투자 환경을 구성할 수 있다. 이 시스템은 반응형 웹 기반으로 개발되어 PC 및 모바일 환경 모두에서 접근 가능하며, 외부 금융 데이터 API와 연동해 최신성을 유지하고, 사용자의 입력과 대화 맥락을 기반으로 AI가 지능적인 답변을 제공하는 것을 목표로 한다.

## 1. 요구사항 정의 (Requirements description)

- **1. 계정관리**
  - **1.1. 회원가입**
    - 1.1.1 초기 페이지에서 회원가입 버튼을 통해 회원가입 페이지로 이동한다
    - 1.1.2 아이디와 비밀번호를 입력하여 계정을 생성한다
    - 1.1.3 다른 유저와 ID가 중복될 시 중복 메시지를 표시한다
    - 1.1.4 비밀번호를 두번 입력받고 일치하지 않으면 불일치 메시지를 표시한다
  - **1.2. 로그인**
    - 1.2.1 초기 페이지에서 로그인 버튼을 통해 로그인 페이지로 이동한다
    - 1.2.2 아이디와 비밀번호를 입력하여 로그인한다
    - 1.2.3 로그인해야만 알파벳 서비스를 이용할 수 있다 [P:H] # [T← 1.2.4;, 4.*, 5.2.2, 6.1.1]
    - 1.2.4 아이디와 비밀번호가 일치하는 계정이 있으면 로그인에 성공하고 서비스 이용이 시작된다 [P:H] [T→ 1.2.3]
    - 1.2.5 아이디와 비밀번호가 일치하는 계정이 없으면 이메일 또는 비밀번호 불일치 메시지를 표시한다
    - 1.2.6 로그인 실패시 입력했던 아이디는 남겨놓는다
  - **1.3. 로그아웃**
    - 1.3.1 로그아웃 버튼은 채팅 페이지 상단에 위치한다
    - 1.3.2 로그아웃을 누르는 즉시 로그아웃이 처리된다 [P:H] [T→ 1.3.3, 1.3.4]
    - 1.3.3 로그아웃 후 세션이 파기된다 [P:H] [T← 1.3.2]
    - 1.3.4 로그아웃 후 초기 페이지로 이동한다
    - 1.3.5 로그아웃 후 뒤로가기 시 초기 페이지로 이동한다
- **2. 채팅**
  - **2.1. 채팅방 생성**
    - 2.1.1 로그인을 하지 않은 상태일 경우, 접근할 수 없다
    - 2.1.2 사용자는 좌측 사이드바의 '종목 코드' 입력란에 주식 종목 코드(예: AAPL)를 필수로 입력해야 한다.
    - 2.1.3 사용자는 선택적으로 '채팅방 제목' 입력란에 원하는 제목(예: 애플 실적 분석)을 입력할 수 있다. (입력하지 않을 경우 "종목명 채팅"이 기본 제목으로 설정된다.)
    - 2.1.4 '초기화' 버튼을 클릭하면 입력된 종목 코드와 채팅방 제목 내용이 모두 삭제된다.
    - 2.1.5 필수 정보를 입력한 후 '+ 새 채팅' 버튼을 클릭하면 새로운 채팅방이 생성된다. [P:H] [T→ 2.1.6, 2.1.7, 2.1.8]
    - 2.1.6 필수 입력값(종목 코드)이 누락된 상태로 생성을 시도할 경우, "종목 코드를 입력해주세요"와 같은 경고 메시지를 출력한다. [P:H] [T← 2.1.5]
    - 2.1.7 유효하지 않은 종목 코드를 입력하여 생성을 시도할 경우, "유효한 종목 코드를 입력해주세요."와 같은 경고 메시지를 출력한다. [P:H] [T← 2.1.5]
    - 2.1.8 채팅방 생성이 완료되면 좌측 채팅방 목록에 생성된 방이 추가되며, 해당 채팅방이 활성화된다. [P:H] [T← 2.1.5]
  - **2.2. 채팅방 대화**
    - 2.2.1 로그인을 하지 않은 상태일 경우, 접근할 수 없다
    - 2.2.2 채팅방 생성을 하거나 사이드바에서 대화하고자 하는 채팅방을 선택하여 채팅방을 활성화 한다.
    - 2.2.3 하단 빈 입력창에 텍스트를 입력하고 "Enter" 키 또는 '전송(종이비행기 아이콘)' 버튼을 누르면 메시지를 보낼 수 있다.
    - 2.2.4 입력창이 비어있을 경우, "Enter"키나 전송 버튼을 눌러도 메시지가 전송되지 않는다.
    - 2.2.5 메시지가 전송되면 Alpha Bot은 질문을 분석하여 관련된 주식 데이터 및 분석 결과를 응답 메시지로 출력한다.
  - **2.3. 채팅 메시지 저장(북마크)**
    - 2.3.1 사용자가 채팅창 내의 특정 메시지를 저장하고 한다면, Alpha Bot 말풍선 우측 상단에 마우스를 올려둔다.
    - 2.3.2 마우스를 올리면 북마크(별모양 아이콘) 버튼이 드러난다.
    - 2.3.3 사용자가 해당 버튼을 누르면 '북마크에 추가되었습니다.'와 같은 메시지를 출력한다.
    - 2.3.4 북마크된 메시지는 우측 사이드바의 '저장된 메시지' 메뉴에서 확인할 수 있다.
  - **2.4. 채팅 삭제(휴지통 이동)**
    - 2.4.1 좌측 사이드바의 채팅방 목록에서 각 채팅방의 '휴지통' 아이콘을 클릭하여 해당 채팅방을 삭제할 수 있다. [P:H] [T→ 2.4.2]
    - 2.4.2 채팅방 삭제 시, 실수로 인한 삭제를 방지하기 위해 삭제 확인 팝업창("이 채팅방을 휴지통으로 이동하시겠습니까?")을 띄운다. [P:H] [T← 2.4.1]
    - 2.4.3 사용자가 '확인' 버튼을 누르면 해당 채팅방은 휴지통으로 이동한다. [P:H] [T→ 2.4.4]
    - 2.4.4 휴지통으로 이동된 채팅방의 상세 관리는 '휴지통' 메뉴에서 수행한다. [P:H] [T← 2.4.3]
- **3. 사이드바**
  - **3.1. 카테고리**
    - 3.1.1 사용자는 '새 카테고리 추가' 버튼을 통해 새로운 카테고리를 생성할 수 있으며, 카테고리명은 중복될 수 없다.
    - 3.1.2 사용자는 기존에 생성한 카테고리의 이름을 변경할 수 있다.
    - 3.1.3 사용자는 카테고리를 삭제할 수 있으며, 삭제 시 확인 절차를 거친다.
    - 3.1.4 사용자가 생성한 모든 카테고리 목록은 사이드바에 표시되며, 정렬이 가능해야 한다.
    - 3.1.5 사용자는 채팅 메시지를 북마크하여 원하는 카테고리에 저장할 수 있다. [P:H] [T→ 3.1.6~3.1.8, 3.4.1, 3.4.4]
    - 3.1.6 사이드바에서 특정 카테고리를 클릭하면, 해당 카테고리에 속한 북마크 메시지 목록이 표시된다.
    - 3.1.7 카테고리 내의 특정 북마크를 클릭하면, 해당 메시지가 있던 채팅 위치로 화면이 이동 및 포커싱된다. [P:M] [T← 3.1.6; T→ 3.4.4]
    - 3.1.8 사용자는 카테고리에 저장된 개별 북마크를 삭제할 수 있으며, 이 작업은 원본 메시지에 영향을 주지 않는다.
  - **3.2. 휴지통**
    - 3.2.1 사용자가 답변을 삭제할 경우 휴지통으로 이동되어 일정 기간 동안 보관된다. [P:M] [T→ 3.2.2~3.2.5]
    - 3.2.2 사용자는 휴지통 목록에서 항목을 선택하여 복원할 수 있다.
    - 3.2.3 사용자는 휴지통 목록에서 항목을 선택하여 영구적으로 삭제할 수 있다.
    - 3.2.4 영구 삭제는 사용자에게 최종 확인 절차를 거친다.
    - 3.2.5 일정 기간이 지나면 휴지통에 있는 모든 항목은 자동으로 영구 삭제된다. [P:M] [T← 3.2.1]
  - **3.3. 재무제표**
    - 3.3.1 챗봇은 요청된 기업의 재무 상태표, 손익계산서, 현금흐름표와 같은 핵심 재무제표 데이터를 제공한다.
    - 3.3.2 데이터는 신뢰할 수 있는 외부 금융 데이터 API를 통해 제공되며, 최신 정보로 지속적으로 업데이트되어야 한다. [P:H] [T← 5.]
    - 3.3.3 매출액, 영업이익, 순이익 등의 추이를 시각화된 차트 형태로 함께 제공하여 사용자의 이해를 돕는다.
  - **3.4. 채팅기록**
    - 3.4.1 사용자와 챗봇이 주고받는 모든 대화 내용이 저장된다. [P:M] [T→ 3.1.5, 6.1.1]
    - 3.4.2 사용자가 채팅기록을 선택하면 대화 목록이 최신순으로 정렬되어 표시된다.
    - 3.4.3 목록에서 특정 대화를 구분할 수 있도록 대화의 핵심 내용이 요약되어 함께 표시된다.
    - 3.4.4 대화 목록에서 대화를 클릭하면 해당 대화의 내용이 현재 채팅 화면에 표시된다. [P:M] [T← 3.1.7]
    - 3.4.5 대화 기록을 선택하여 삭제할 수 있다.
- **4. 뉴스/공시 요약**
  - **4.1 수집 및 필터링**
    - 4.1.1   시스템은 선택 종목·키워드 기반으로 최신 뉴스/공시를 수집한다.
    - 4.1.2   결과가 없을 경우 ‘관련 소식이 없습니다’ 메시지를 표시한다.
  - **4.2 요약/감성**
    - 4.2.1   사용자는 ‘요약 보기’ 토글로 3~5문장 요약을 확인할 수 있다.
    - 4.2.2   시스템은 긍정/중립/부정 감성 라벨을 표시한다.
    - 4.2.3   자동 요약 실패 시 원문 카드만 제공하고 재시도 버튼을 표시한다.
  - **4.3 출처 및 시점**
    - 4.3.1   각 카드에 매체명, 게시 시각, 원문 링크를 표시한다.
    - 4.3.2   시세 관련 답변과 혼동 방지를 위해 기사 시점을 명확히 표기한다(예: KST).
- **5. 시스템 설정 및 보안**
  - **5.1 계정/프로필**
    - 5.1.1   사용자는 프로필 편집 화면에서 닉네임·연락 옵션 등을 수정할 수 있다.(3.1과 독립)
    - 5.1.2   비밀번호 변경 시 현재 비밀번호 검증 및 최소 강도 기준을 적용한다.
    - 5.1.3   비밀번호 불일치/약함 판단 시 즉시 피드백을 표시한다.
  - **5.2 세션/접근 제어**
    - 5.2.1   로그인 후 일정 시간 무활동 시 자동 로그아웃하고 이유를 안내한다(1.3.3과 합치).
    - 5.2.2   인증이 필요한 페이지 접근 시 미인증 사용자는 로그인 페이지로 리다이렉트한다. [P:H] [T↔ 1.2.3]
  - **5.3 데이터 보호/감사**
    - 5.3.1   민감 정보는 전송·저장 시 암호화한다.
    - 5.3.2   주요 행위(로그인 실패 연속, 관리자 기능 사용 등)는 감사 로그에 기록한다.
    - 5.3.3   시스템 오류 발생 시 추적 ID를 포함한 표준화된 오류 페이지를 제공한다.
- **6. 커뮤니티/코멘트**
  - **6.1 종목 토론**
    - 6.1.1   사용자는 각 종목 상세 화면에서 댓글을 작성할 수 있다. [P:M] [T↔ 1.2.3]
    - 6.1.2   댓글은 작성자명, 시각과 함께 표시되며, 최신순 정렬이 기본이다.
    - 6.1.3   로그인하지 않은 경우 작성 버튼은 비활성화된다.
