# Software Requirements Specification (SRS) (& System testing)

**Project title:** AlphaBot

**Project description:** AlphaBot은 인공지능 기반 주식 챗봇 웹 애플리케이션으로, 사용자가 자연어로 질문을 입력하면 주식 종목의 실시간 정보, 뉴스 및 공시 요약을 대화형 인터페이스를 통해 제공한다. 본 시스템은 단순한 종목 검색을 넘어, 사용자 계정 관리, 검색 기록 및 카테고리 관리, 커뮤니티 댓글 기능까지 포함하여 투자자가 보다 효율적이고 편리하게 주식 관련 정보를 탐색할 수 있도록 설계되었다. 또한 사용자 맞춤형 대시보드, 보안 및 데이터 보호 기능을 통해 안정성과 신뢰성을 강화하며, 사용자는 북마크, 휴지통 등 다양한 보조 기능을 활용해 자신만의 투자 환경을 구성할 수 있다. 이 시스템은 반응형 웹 기반으로 개발되어 PC 및 모바일 환경 모두에서 접근 가능하며, 외부 금융 데이터 API와 연동해 최신성을 유지하고, 사용자의 입력과 대화 맥락을 기반으로 AI가 지능적인 답변을 제공하는 것을 목표로 한다.
